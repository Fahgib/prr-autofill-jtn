Cara Kerja Live Sync:

Setiap kali Anda Paste foto (Ctrl+V), klik Data Kosong (Skip), atau mengubah isi tabel, aplikasi otomatis mengirim perubahan ke Google Spreadsheet Anda detik itu juga.

Didapat dari menu Ekstensi → Apps Script → Terapkan (Deploy) → Aplikasi Web di Google Spreadsheet Anda.

Pengaturan Mesin Ekstraksi Foto

Aplikasi ini memiliki Dual-Engine:

  • Gemini Vision AI: Menggunakan variabel GEMINI_API_KEY di Vercel atau API Key di bawah ini.
  • Smart OCR Lokal (Tesseract.js): 100% gratis tanpa API Key, mendukung kode unit 410 & 54410 serta koreksi otomatis angka Romawi (1I → II).
